# Interactive Solar System Explorer

An AI-assisted, browser-based 3D Solar System visualization project. It uses Three.js for the 3D scene and Tailwind CSS for much of the interface styling.

## Project Structure

```text
Solar-System-Explorer/
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── data.js
│   └── main.js
├── README.md
└── .gitignore
```

## Run Locally

1. Open this repository folder in VS Code.
2. Start `index.html` using the **Live Server** extension, or open it in a modern browser.
3. Keep an internet connection available because the project loads some libraries and fonts from CDNs.

If opening the page directly causes browser restrictions, use Live Server.

## Current Organization

- `index.html` — Page markup and external library imports.
- `css/styles.css` — Custom CSS styles.
- `js/data.js` — Celestial-body, moon, and mission data.
- `js/main.js` — Simulation logic and user-interface behavior.

This project reorganizes a provided single-file implementation. Scientific values and behaviors have not necessarily been independently verified.
